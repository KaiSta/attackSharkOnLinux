Attack Shark X11 — can Chromium's WebHID reach the receiver?

Attack Shark's browser-based configuration tool is a WebHID application. This page uses the same API to find out whether WebHID works against this mouse's receiver on Linux — the part that cannot be determined without trying it.

This page only reads. It never calls sendReport or sendFeatureReport, so it cannot change a single setting on the mouse. Nothing is sent anywhere except back to the tiny local server that served this page, which writes the result to a file on this machine.

Click Connect the receiver, then choose the entry for 1d57:fa60 (it may be listed as Xenta 2.4G Wireless Device or similar) in the dialog and press Connect. Leave the tab open for about five seconds afterwards.
